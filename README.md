# Snowden Builders Authority Site — Foundation Release

This is a deployable Next.js foundation for a replacement SnowdenBuilders.com site.

## What is included

- Responsive design system
- Homepage
- Custom homes page
- Build-on-your-lot page
- Process page
- Project framework
- Resource center and reusable article routes
- Priority location hub and reusable local routes
- Contact/qualification form interface
- Organization, service, FAQ and article structured data
- Metadata, robots and sitemap generation
- Content safeguards identifying facts that require Snowden review

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Deploy

The code can deploy to Vercel or another Node-compatible host. Keep the existing website live until:

1. Content and claims are approved.
2. Real photography is inserted.
3. The form is connected.
4. Analytics, Search Console and consent tools are configured.
5. Existing URLs are crawled and mapped to new URLs.
6. Redirects are tested.
7. Schema is validated.
8. Performance and accessibility checks pass.
